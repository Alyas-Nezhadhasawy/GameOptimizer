## معرفی

Gaming Optimizer یک ابزار بهینه‌سازی دسکتاپ برای ویندوز ۱۰ و ۱۱ است، برای
کاربرانی که همان سطح از کنترل ابزاری مثل *Opeasy* را می‌خواهند — حذف
برنامه‌های اضافی، تغییرات رجیستری و BCD، پاور پلن، تنظیمات GPU، شبکه، RAM
و اولویت پردازشی هر بازی — همه در قالب یک برنامه‌ی نیتیو با ظاهر تیره‌ی
مشکی و قرمز و پشتیبانی کامل از دو زبان فارسی و انگلیسی.

هر سوییچ در برنامه به یک شیء `Tweak` با متدهای `apply()`, `revert()` و
`is_applied()` وصل است. هیچ تغییری یک‌طرفه نیست: هر عملیات قابل بازگشت
است، و هر تب هنگام باز شدن یک اسکن پس‌زمینه انجام می‌دهد تا سوییچ‌هایی که
از قبل اعمال شده‌اند (چه با همین برنامه، چه دستی، چه با ابزار دیگری)
خودشان روشن شوند و نیازی به تکرار کار نباشد.

## امکانات

| Start | ساخت System Restore Point و Export رجیستری قبل از هر تغییری؛ حذف برنامه‌های اضافی؛ غیرفعال‌سازی Windows Update. |
| Registry & BCD Tweaks | مجموعه‌ای منتخب از تغییرات رجیستری و `bcdedit` برای کاهش تاخیر ورودی و بهبود واکنش‌پذیری سیستم. |
| Windows Settings | اعمال دسته‌جمعی تنظیمات مهم ویندوز برای گیمینگ (افکت‌های بصری، اعلان‌ها، فعالیت پس‌زمینه و موارد دیگر). |
| Control Panel | تنظیمات صدا، ماوس و گرافیک در Control Panel، بدون نیاز به باز کردن دستی. |
| Power Plan | ساخت و فعال‌سازی یک پاور پلن پرقدرت مخصوص گیمینگ. |

| Game Presets | مرور ۱۰۰ بازی محبوب همراه با پوستر و مشاهده‌ی راهنمای بهترین تنظیمات هر بازی. |

| Unwanted Services | غیرفعال‌سازی سرویس‌های ویندوز که فقط بار پس‌زمینه اضافه می‌کنند و برای گیمینگ سودی ندارند. |
| MSI Mode Tools | تغییر کنترلرهای پشتیبانی‌شده‌ی GPU / حافظه / شبکه / USB به حالت Message-Signaled Interrupts. |
| GPU Tweaks | تنظیمات سطح پایین‌تر رجیستری GPU، فراتر از کنترل پنل سازنده. |
| Network Tweak | تنظیم پشته‌ی TCP/IP و آداپتور شبکه برای کاهش تاخیر (Latency). |
| Ram Process | آزادسازی و مدیریت RAM مصرف‌شده توسط پردازش‌های پس‌زمینه. |
| Adobe High Performance | اعمال پروفایل کارایی GPU/CPU پشتیبانی‌شده توسط نرم‌افزارهای Adobe، برای کاربرانی که هم تولید محتوا دارند و هم بازی می‌کنند. |
| Game High Priority | تنظیم اولویت CPU برای یک بازی مشخص، یا ساخت یک فایل مستقل `GameHighPriority.reg` برای اجرای بعدی با دابل‌کلیک. |
| Startup / Autorun Apps | اسکن هم‌زمان Registry Run keys، پوشه‌ی Startup و Scheduled Tasks با تریگر «At log on» در یک لیست؛ غیرفعال‌سازی هیچ‌چیزی را حذف نمی‌کند، فقط جابه‌جا می‌کند تا دقیقاً قابل بازگردانی باشد. |

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- پایتون ۳.۱۰ یا بالاتر (فقط برای اجرا از سورس؛ فایل exe نهایی به چیزی نیاز ندارد)
- دسترسی Administrator — برنامه خودش با درخواست UAC دوباره با دسترسی بالا اجرا می‌شود، چون تغییر رجیستری و سرویس‌ها به آن نیاز دارد

## شروع به کار

```bash
pip install -r requirements.txt
python main.py
```

در اولین اجرا از شما زبان (فارسی یا انگلیسی) پرسیده می‌شود؛ این انتخاب
برای باقی جلسه استفاده می‌شود.

## ساخت فایل exe مستقل

```bash
pyinstaller --noconfirm --onefile --windowed --name "GamingOptimizer" ^
    --add-data "assets;assets" main.py
```

فایل خروجی در مسیر `dist/GamingOptimizer.exe` قرار می‌گیرد.

## یادداشت‌های طراحی

**چرا هر تنظیم یک شیء `Tweak` است.** هر آیتم متدهای `apply()`, `revert()`
و `is_applied()` را دارد. این یعنی سه چیز رایگان: بک‌آپ خودکار از مقدار
قبلی پیش از هر تغییر (در مسیر `%PROGRAMDATA%\GamingOptimizer\backups\*.json`)،
دکمه‌ی «بازگردانی به حالت پیش‌فرض» که همیشه کار می‌کند — حتی برای
مقادیر رجیستری که قبلاً اصلاً وجود نداشتند (به‌درستی حذف می‌شوند، نه صفر
می‌شوند) — و یک اسکن دقیق در لحظه‌ی باز شدن هر تب که وضعیت واقعی سیستم را
نشان می‌دهد.

**چرا سایدبار به‌جای اسکرین‌شات، آیکون تولیدشده دارد.** اسکرین‌شات از
NVIDIA Control Panel، AMD Software یا تنظیمات ویندوز، رابط کاربری
کپی‌رایت‌شده‌ی شرکت‌های دیگر است و گنجاندن آن در برنامه‌ای که توزیع
می‌شود ریسک قانونی دارد. به‌جای آن، یک ست آیکون یکدست با Pillow ساخته
شده است (`core/icon_generator.py`؛ برای بازسازی: `python -m core.icon_generator`).

**تم رنگی.** کل رابط کاربری پالت رنگی خود را از فایل
`assets/theme/black_red.json` می‌خواند (بارگذاری‌شده از طریق
`core/theme.py`)، به‌همین دلیل هر ویجت بدون رنگ اختصاصی — دکمه‌ها،
سوییچ‌ها، نوار پیشرفت، اسکرول‌بار — از همان ظاهر مشکی و قرمز پیروی
می‌کند، نه از رنگ پیش‌فرض کتابخانه. تغییر تم کل برنامه یعنی ویرایش همین
یک فایل.

## بومی‌سازی

انتخاب زبان فقط یک‌بار، در صفحه‌ی اسپلش و پیش از ساخته‌شدن پنجره‌ی
اصلی، انجام می‌شود — پس نیازی به رندر مجدد در وسط جلسه نیست. رشته‌های UI
از طریق `core/i18n.py` خوانده می‌شوند؛ نام و توضیح هر Tweak به‌طور
پیش‌فرض فارسی است (نسخه‌ی اصلی) و معادل انگلیسی روی آن قرار می‌گیرد.

## مشارکت

Issue و Pull Request خوش‌آمد هستند. لطفاً تنظیمات جدید را به‌صورت شیء
`Tweak` در `data/` اضافه کنید، کد UI را در `ui/`/`tabs/` نگه دارید، و
پیش از ارسال تغییراتی که به `core/` مربوط می‌شوند، برنامه را روی یک
سیستم واقعی ویندوز تست کنید      .
